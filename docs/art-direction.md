# 화면 디자인 지침 (고전 어둠의 전설 풍)

이 문서는 맵·물체·분위기·말풍선 같은 화면 그림을 고전 어둠의 전설 인게임 화면과 최대한 같은 느낌으로 맞추기 위한 기준입니다.
사용자가 보내 준 원작 화면 예시 세 장(R1~R3)을 글로 옮겨 적었습니다. 그림을 고칠 때는 이 문서를 기준으로 판단합니다.

## 0. 지켜야 할 것

- **원작의 그림 파일, 스크린샷 픽셀, 로고, UI 이미지를 추출·복사·트레이싱하지 않습니다.** 모든 그림은 코드(캔버스 절차 생성)로 새로 그립니다.
  맞추는 것은 시점, 비율, 색감, 질감의 밀도, 물체의 종류와 배치 같은 "양식"입니다.
- 시점은 지금처럼 2:1 아이소메트릭(타일 64×32, 벽 높이 40)입니다.
- 결정적(deterministic)으로 그립니다. 같은 맵의 같은 칸은 언제 그려도 같은 모양이어야 합니다 (`hash2`, `seeded` 사용, 그릴 때 `Math.random` 금지).

## 1. 원작 예시 세 장

### R1 — 저녁 숲길 (어둑함)

- 화면 전체가 **짙은 녹색 풀밭**. 바탕 `#2c4a1c` 근처, 그 위에 더 어두운 얼룩(`#1b3011`)이 지름 20~60px 크기로 불규칙하게 번져 있고, 밝은 녹색 점(`#4d6e2a`)이 1~2px 크기로 촘촘히 흩뿌려져 있다. **타일 경계선은 전혀 보이지 않는다.**
- **흙길**: 폭 1.5~2.5칸, 굽이치다가 Y자로 갈라진다. 바탕 `#5c3a1f`, 밝은 점 `#7a4d2a`, 어두운 점 `#3d2412`.
  가장자리는 직선이 아닌 들쭉날쭉한 곡선이고, 풀과 맞닿는 가장자리에 1~3px의 어두운 테두리(`#1e2a10`)가 있어 길이 살짝 패인 느낌이 난다.
  길 위에 작은 나뭇가지(갈색 2px 선, 길이 4~8px)와 작은 돌멩이(회갈색 2~3px)가 드문드문 있다.
- **게시판** 두 개가 길가에 서 있다. 나무 기둥 두 개(`#4a3220`) 위에 가로로 긴 판(`#7a5a36`, 폭 약 1칸, 높이 약 0.6칸), 판 위에 지붕처럼 덮인 나무 처마(`#3e2a18`).
  판에 흰 종이(`#e8e4d8`) 3~4장이 붙어 있고 종이마다 검은 글씨 줄(짧은 가로선 2~3개)이 있다.
- **조명**: 화면 가장자리로 갈수록 어두워지는 강한 비네트. 네 모서리는 거의 검정이고 가운데 넓은 타원만 밝다. 어둠의 경계는 아주 부드럽다.
- 캐릭터는 머리:몸 ≈ 1:5의 작은 도트 캐릭터이고 키는 약 1.6칸이다.

### R2 — 마을 광장 (낮, 사람 많음)

- **밝고 채도 높은 잔디**. 바탕 `#2f7d24`, 밝은 점 `#45a032`, 어두운 점 `#22631a`가 1px 단위로 아주 촘촘히 디더링되어 카펫 같은 질감이다. 큰 얼룩은 약하다.
- **석상 두 개**: 원기둥 받침대(지름 약 1.5~2칸, 높이 약 1칸). 밝은 회백색 돌(`#b0a898`, 그림자 `#6e675c`)이고 위아래에 장식 띠(몰딩)가 2~3줄 있으며, 받침 아래에 넓은 둥근 바닥돌이 있다.
  받침 위에 사람 키의 1.5배쯤 되는 회색 석상(로브 입은 여인상, 무기를 든 전사상)이 돌 질감 명암으로 서 있다.
- 화면 왼쪽 위와 오른쪽 아래 가장자리에 대각선으로 이어지는 **낮은 돌담**이 있다. 회색 돌(`#8a8a80`)이고 담 옆면에 **켈트 매듭 무늬 띠**(어두운 선으로 그린 엮인 무늬)가 새겨져 있으며 윗면은 밝은 갓돌이다.
- **말풍선**: 흰 바탕의 둥근 사각형, 1px 검은 테두리, 검은 12px 글씨. 내용은 `이름: 대사` 형식이고 한 줄에 약 14~16자씩 여러 줄로 줄바꿈된다. 아래쪽에 말하는 사람을 가리키는 작은 꼬리가 있다.
- 화면 아래 메시지 줄은 어두운 갈색 바탕에 **노란 글씨**(`#f0e040` 근처)로 외침과 공지를 보여 준다.
- 머리 위에 캐릭터 이름이 늘 떠 있지는 않다.

### R3 — 섬의 성소 (낮)

- **물**: 진한 파랑(`#1d55a0`) 바탕에 밝은 파랑(`#3a78c4`) 물결 띠와 흰 거품(`#dce8f4`) 붓질이 대각선 방향으로 흐른다.
  물가에는 **큰 회색 바위**(바탕 `#55555a`, 윗면 밝은 `#9a9a9e`, 아래 그림자 `#26262a`)가 촘촘히 늘어서 해안선을 이룬다. 바위 하나는 0.5~1.2칸 크기이고 서로 겹친다.
- **풀**: 중간 녹색(`#3a7424`) 바탕에 어두운 덩어리(`#24501a`)와 노란빛이 도는 밝은 풀잎 터치(`#62983a`)가 붓으로 찍은 듯 있다.
- **흙**: 밝은 갈색(`#a06c3a`) 덩어리이고 가장자리가 부드럽다.
- **나무**: 가늘고 긴 갈색 줄기(`#5a3a1e`). 잎은 위아래로 2~4개의 덩어리가 겹친 형태이며, 바탕 `#2f6a22`, 빛 받는 쪽 `#7cb848`, 어두운 안쪽 `#1a3e14`이다. 잎 덩어리 가장자리가 잎 모양으로 들쭉날쭉하고 나무 키는 약 3칸이다.
- **성소**: 정사각형 돌 단상이 3단 계단으로 쌓여 있다. 옅은 베이지 돌 `#c4b898`, 줄눈 `#8a7e64`, 계단 옆면은 더 어두운 `#9a8e72`이다.
  단상 테두리를 따라 **기둥 8개**가 있다. 홈이 파인 베이지 몸통 위에 **금색 돔 머리**(`#d0a040`, 밝은 쪽 `#f0d070`, 어두운 띠 `#6a5020`)가 얹혀 있다.
  가운데에 **원형 샘**: 밝은 하늘색 물(`#48c8e8`, 가운데가 더 밝음)과 해 모양으로 톱니진 금 테두리(`#d8b040`).
- 왼쪽 끝에 굵은 나무 말뚝과 밧줄로 된 **울타리**, 앞쪽에 고사리처럼 뾰족한 잎의 덤불이 있다.

## 2. 공통 양식

- **질감**: 모든 바닥은 "손으로 찍은 픽셀" 느낌이다. 큰 얼룩과 작은 점(1~2px)을 여러 겹 겹쳐 채우고, 타일 경계가 보이지 않게 이어진다. 흐릿한 그라데이션 덩어리(벡터 그림 느낌)는 쓰지 않는다.
- **선명도**: 화면 배율(devicePixelRatio)과 상관없이 점이 또렷해야 한다. 질감의 "점 크기"는 CSS 1px 기준으로 정하고, 캐시 캔버스는 실제 화면 픽셀 해상도로 만들어 1:1로 그린다. 소수 배율(1.25, 1.5)에서 최근접 확대를 쓰면 점 크기가 들쭉날쭉해지므로 쓰지 않는다.
- **색**: 녹색과 흙색은 채도가 높고 짙다. 그림자는 검정이 아니라 같은 색 계열의 어두운 톤이다.
- **물체 명암**: 빛은 왼쪽 위에서 온다(왼쪽·윗면이 밝고 오른쪽·아래가 어둡다). 외곽선은 굵은 검정 선 대신 같은 계열의 어두운 색으로 그리고, 바닥에는 부드러운 타원 그림자를 깐다.
- **크기**: 캐릭터 키 ≈ 1.6~2칸, 나무 ≈ 2.5~3칸, 석상(받침 포함) ≈ 3칸, 기둥 ≈ 2.5칸, 게시판 ≈ 1.6칸.
- **경계**: 서로 다른 바닥이 만나는 곳은 노이즈로 흔들린 유기적인 경계로 섞인다. 풀이 흙·돌 위로 살짝 덮어 들어가고, 흙길의 풀 쪽 가장자리에는 어두운 테두리가 있다. 돌바닥(판석·단상·자갈)은 경계가 조금 더 또렷하다.

## 3. 타일 문자와 그림 대응

| 문자 | 이름 | 그림 기준 |
| --- | --- | --- |
| `.` `:` `f` | 풀밭 / 꽃밭 / 우거진 풀 | R2(마을·훈련장·평원) 또는 R3 풀. `:`는 작은 꽃 점, `f`는 뾰족한 풀·고사리 포기(걸어서 지나갈 수 있는 바닥 장식) |
| `,` | 흙길 | R1 흙길 (어두운 테두리, 잔가지·돌멩이) |
| `=` | 돌바닥(자갈) | 둥근 자갈이 촘촘히 박힌 길, 회갈색 |
| `g` | 판석 광장 | 큰 사각 판석이 어긋나게 깔린 광장, 줄눈과 이끼 낀 틈 |
| `d` | 돌 단상 | R3 단상 윗면 (베이지 판석), 앞쪽 두 변에 2~3단 계단 옆면이 보인다 |
| `_` `m` `-` `;` `s` `a` `v` `x` `k` | 나무 바닥 / 대리석 / 던전 / 동굴 / 모래 / 잿빛 땅 / 늪 / 심연 / 뼈 | 같은 양식(노이즈 질감, 이음매 없음)으로 다시 그린다 |
| `~` | 물 | R3 물: 진한 파랑, 대각선 물결 띠, 흰 거품, 물가의 흰 물보라 |
| `U` | 성수 | R3 원형 샘: 밝은 하늘색, 땅과 맞닿는 가장자리에 금빛 톱니 테두리 |
| `L` | 용암 | 같은 질감 양식의 붉은 용암 |
| `Q` | 바위 무더기 | R3 해안 바위: 크고 작은 회색 바위 2~4개가 겹친 덩어리 |
| `R` `r` | 바위 / 동굴 바위 | 단독 바위 (R3 바위와 같은 양식) |
| `T` `E` `P` `Y` | 나무 / 활엽수 / 전나무 / 고목 | R3 나무 양식 (잎 덩어리 겹침, 왼쪽 위 빛). `E`는 더 가늘고 키 큰 나무 |
| `B` | 덤불 | 잎이 들쭉날쭉한 낮은 덤불 |
| `N` | 게시판 | R1 게시판 (처마 달린 판, 흰 종이 3~4장) |
| `S` | 석상 | R2 석상 (둥근 장식 받침 + 회색 인물상, 칸마다 여인상/전사상 변형) |
| `I` | 기둥 | R3 기둥 (홈 파인 베이지 몸통 + 금색 돔 머리) |
| `p` | 돌 말뚝 | 무릎 높이의 짧은 돌 기둥 |
| `F` | 울타리 | R3 울타리 (굵은 나무 말뚝 + 밧줄) |
| `u` | 그루터기 | 나이테가 보이는 잘린 나무 밑동 |
| `l` | 가로등 | 쇠기둥 위 등불(따뜻한 빛, 밤·던전에서 빛을 냄) |
| `h` | 낮은 돌담 | R2 돌담 (허리 높이, 옆면에 켈트 매듭 띠, 밝은 갓돌) |
| `#` `D` `K` `X` `H` `W` | 돌벽 / 던전 벽 / 동굴 벽 / 심연 벽 / 신전 벽 / 나무벽 | 같은 질감 양식. 돌벽은 쌓은 돌 무늬, 신전 벽은 밝은 돌에 금색 띠, 나무벽은 통나무 |
| 그 밖 (`C` `O` `A` `G` `w` `t` `c` `j` `n`) | 상자, 통, 제단, 묘비, 우물, 탁자, 수정, 횃불, 노점 | 같은 명암·질감 양식으로 다시 다듬는다 |

## 4. 분위기

- 모든 맵에 화면 가장자리 비네트를 둔다. 세기는 맵 분위기에 따른다: 마을·훈련장(낮) 약하게, 평원(흐림) 중간, 숲(저녁, R1) 강하게, 던전(어둠) 가장 강하게 (지금처럼 빛 구멍과 함께).
- 맵 분위기는 클라이언트의 맵 id 표로 정한다 (서버 데이터를 바꾸지 않는다).

## 5. 글자와 말풍선

- 말풍선은 R2처럼: 흰 바탕 둥근 사각형, 1px 검은 테두리, 검은 12px 글씨, `이름: 대사` 형식, 한 줄 약 16자에서 줄바꿈(최대 4줄), 말하는 사람을 가리키는 꼬리.
- 외침·공지는 노란 글씨로 보여 준다.
