어둠의 전설을 **내 서버에서만** 즐기기 위한 개인 서버의 첫 릴리즈입니다. 게임 서버, 웹 게임 화면, 웹 관리자 페이지가 한 꾸러미에 들어 있고, 외부 서비스 없이 혼자 돌아갑니다.

## 설치와 실행

[Node.js](https://nodejs.org) 20.10 이상(22 권장)이 필요합니다. 아래 `legend-of-darkness-v1.0.0.tar.gz`(또는 `.zip`)를 받아 풉니다.

```bash
tar xzf legend-of-darkness-v1.0.0.tar.gz
cd legend-of-darkness-v1.0.0
npm ci --omit=dev
cp .env.example .env      # 선택: 포트, 관리자 비밀번호, 경험치 배율 등
npm start
```

- 게임: `http://서버주소:7777/` · 관리자 페이지: `http://서버주소:7777/admin`
- 캐릭터가 하나도 없는 상태로 켠 뒤 처음 만든 캐릭터가 관리자가 됩니다. 게임 안에서 **F2** 가 운영자 도구입니다.
- 소스에서 빌드하거나 Docker 로 돌리는 방법은 README 의 "빠른 시작"을 보세요.

## 이번 판에 들어 있는 것

**원작 풍 화면**
- 2:1 아이소메트릭 화면, 손으로 찍은 듯한 도트 바닥(타일 경계 없음), 원작 예시 화면을 따른 나무·바위·석상·성소·게시판·돌담
- 맵마다 분위기(낮·흐림·저녁 숲·던전 어둠)와 화면 가장자리 비네트
- 약 5등신의 도트 캐릭터 (11개 직업 의상, 남녀, 머리 모양·색, 무기·투구·방패), 초상화·접속 화면은 SD 일러스트
- 클래식 아래 가죽 패널, 반투명 말풍선(`이름: 대사`), 초록 외침 줄, 도트 글꼴, 이름표는 마우스를 올리거나 대상으로 고를 때만

**직업과 성장 (원작 규칙)**
- 1차 직업 5종 (전사·도적·마법사·성직자·무도가)과 2차 직업 5종 (검투사·궁사·소환사·바드·수인 — 포유류·조류·파충류)
- **전직**: 99레벨에서 1레벨부터 다시 (같은 직업도 가능), 능력치만 처음으로 돌아가고 배운 기술·마법과 숙련도는 그대로. 무도가는 **환골탈태**로만
- **승급**: 경험치를 팔아 최대 체력·마나, 최대 체력 150 을 팔아 능력치 1, 조건을 채우면 "마스터"
- **2차 전직**: 승급 뒤 경험치 10억과 체력·마력 500. 레벨은 99 그대로이고 **어빌리티 레벨** 1~99 가 원작처럼 긴 목표로 오름. 2차 직업은 이어받은 1차 직업보다 늘 강하게
- **원작식 기술 배우기**: 길드장에게 레벨(2차 직업은 어빌)·골드·재료·**선수과목**(먼저 배운 기술의 숙련도)으로 배움. 기술마다 **숙련도** 0~100 (쓸수록 오르고 위력 70% → 115%), **K 키** 스킬트리 창, 기술 잊기
- **자동사냥** (Z, 설정은 Shift+Z): 서버가 대신 걷고 싸우고 회복하고 줍기 — 브라우저 탭을 내려 두어도 계속

**세계**
- 맵 9곳 (마을, 숲과 성소, 지하묘지 1·2층, 잿빛 평원, 수정 동굴, 망자의 탑, 어둠의 심연, 수련장), 몬스터 35종(보스 6종 포함), 소환수 6종
- 아이템 257종, 기술·마법 128종, NPC 22명 (상점·전직·승급·2차 직업 인도자·창고·순간이동 등)

**관리자 (캐릭터를 빠르고 자유롭게 키우기)**
- 게임 안 **F2 운영자 도구**와 채팅 명령 40여 개 (`/만렙 전사`, `/레벨 99`, `/어빌 30`, `/숙련도 전부` …)
- 웹 관리자 페이지: 캐릭터 검색·편집, 서버 설정(경험치·골드·드롭 배율, 가입 방식), 작업 기록
- **직업·스킬트리 편집기**: 스킬트리 칸 배치와 선수과목·배우는 조건, 전직·승급·2차 전직·어빌·숙련도 규칙을 고치면 **서버를 끄지 않고 바로 반영**, 판 기록에서 되돌리기

## 알아 둘 것
